# Online Dars — himoyalangan kurs platformasi

| Papka | Nima | Holat |
|---|---|---|

| [`teacher-panel/`](teacher-panel/README.md) | O'qituvchi web paneli (Next.js) | kurslar, o'quvchilar, video darslar, jonli efir, hodisalar jurnali |
| `mobile/` | Flutter o'quvchi ilovasi | keyingi bosqich |
